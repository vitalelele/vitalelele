## 🧠 About Me

I got into security because I like understanding how things work, and the fastest way to do that is to see how they break.

Real-world pentesting turned out to be less "hacker movie" and more:
- testing stuff by hand until something behaves weirdly
- figuring out if it's a real issue or just noise
- writing it up so someone can actually fix it

And since a lot of that work is repetitive, I write scripts to automate the boring parts.
